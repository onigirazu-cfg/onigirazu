## 🔧 Usage Examples

### Basic Package Operations

```go
// Install package
pm.Install(ctx, "nginx")

// Search for packages
results, _ := pm.Search(ctx, "web server")

// List installed packages
installed, _ := pm.ListInstalled(ctx)
```

### Enterprise Features

```go
// Create snapshot before upgrade
pm.CreateSnapshot(ctx, "pre-upgrade")

// Install package group
pm.InstallGroup(ctx, []string{"nginx", "mysql", "php"})

// Check system health
health, _ := pm.RunHealthCheck(ctx)
fmt.Printf("Health Score: %d/100\n", health.Score)

// View audit log
log := pm.GetAuditLog()
```
