# 🚀 Швидкий старт: insecure_ignore_host_key

## Питання: Як можна передати insecure_ignore_host_key?

### Відповідь за 30 секунд

```yaml
# inventory.yml
groups:
  all:
    vars:
      insecure_ignore_host_key: true  # ⚠️ Тільки для dev/test!

hosts:
  myhost:
    address: 192.168.1.10
```

```bash
onigirazu-cli run -i inventory.yml playbook.yml
```

**Готово!** ✅

---

## ⚠️ Важливо

### ❌ Це НЕ працює

```text
# inventory.txt
192.168.1.10
# Текстовий формат не підтримує insecure_ignore_host_key!
```

```yaml
# playbook.yml
tasks:
  - name: Run command
    shell:
      command: hostname
      insecure_ignore_host_key: true  # ❌ Не працює!
```

### ✅ Це працює

```yaml
# inventory.yml
hosts:
  myhost:
    address: 192.168.1.10
    insecure_ignore_host_key: true  # ✅ Працює!
```

---

## 🎯 Три способи налаштування

### 1. Для одного хоста

```yaml
hosts:
  dev-server:
    address: 192.168.1.10
    insecure_ignore_host_key: true
```

### 2. Для групи хостів

```yaml
groups:
  dev-servers:
    hosts:
      - server-01
      - server-02
    vars:
      insecure_ignore_host_key: true
```

### 3. Для всіх хостів

```yaml
groups:
  all:
    vars:
      insecure_ignore_host_key: true
```
