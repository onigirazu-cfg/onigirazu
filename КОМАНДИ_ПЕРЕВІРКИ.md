## 🧪 Інтеграційне тестування

### Тест модуля config (простий)

```bash
./onigirazu playbook test-config-simple.yml -i test-inventory-ubuntu.yml
```

**Що перевіряється:**

- ✅ Створення конфігурації на віддаленому хості
- ✅ Встановлення значень
- ✅ Отримання значень
- ✅ Видалення ключів

---

### Тест модуля config (розширений)

```bash
./onigirazu playbook test-config-module.yml -i test-inventory-ubuntu.yml
```

**Що перевіряється:**

- ✅ Всі операції з простого тесту
- ✅ Backup та restore
- ✅ Різні формати (JSON, YAML)
- ✅ Idempotency

---

### Тест з debug режимом

```bash
./onigirazu playbook test-config-simple.yml -i test-inventory-ubuntu.yml -vvv
```

**Що показує:**

- Детальні логи виконання
- SSH команди
- Результати кожної операції

---

### Тест у check mode (dry run)

```bash
./onigirazu playbook test-config-simple.yml -i test-inventory-ubuntu.yml --check
```

**Що робить:**

- Перевіряє, що буде зроблено
- Не вносить реальних змін
- Показує, які зміни будуть застосовані

## 🐛 Troubleshooting

### Проблема: Помилка компіляції

```bash
# Очистити кеш
go clean -cache

# Оновити залежності
go mod tidy

# Спробувати знову
go build ./...
```

---

### Проблема: Тести не проходять

```bash
# Очистити кеш тестів
go clean -testcache

# Запустити тести з verbose
go test ./... -v

# Запустити конкретний тест
go test ./internal/core -v -run TestCoreEngine_executePlay
```

---

### Проблема: SSH з'єднання не працює

```bash
# Перевірити SSH ключ
ls -la ~/.ssh/id_rsa

# Перевірити права доступу
chmod 600 ~/.ssh/id_rsa

# Тестове підключення
ssh -i ~/.ssh/id_rsa -v usx@cs.rastiegaiev.com
```

---

### Проблема: Модуль не знайдено

```bash
# Перевірити реєстрацію модуля
grep -r "RegisterModule.*Config" internal/modules/

# Перевірити security validator
grep -r "config" internal/security/validator.go
```
