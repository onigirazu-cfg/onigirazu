# Onigirazu Logo

## Design Concept

The Onigirazu logo represents the core philosophy of the configuration management system:

- **Visual Metaphor**: The logo depicts an onigirazu (Japanese rice ball) with nori (seaweed) wrapping and a central filling
- **Color Scheme**: 
  - Dark green stripes (top/bottom) represent nori (seaweed)
  - Red center stripe represents the filling/core functionality
  - Textured dots create a pixelated, technical aesthetic
- **Typography**: Bold, modern sans-serif for the project name
- **Tagline**: "Configure. Wrap. Deploy." - encapsulates the system's workflow

## Symbolism

The onigirazu metaphor perfectly represents the system's approach to configuration management:

1. **Configure**: Like preparing ingredients for an onigirazu
2. **Wrap**: Like wrapping the configuration in a structured, reliable package
3. **Deploy**: Like delivering the final, well-packaged result

## Usage Guidelines

- Use the logo at 200px width for documentation headers
- Maintain aspect ratio when scaling
- Use on light backgrounds for best contrast
- The tagline should accompany the logo when space allows

## Files

- `logo.png` - Main logo file (200px width recommended)
- `logo.svg` - Vector version for scalable use
- `logo-dark.png` - Dark background variant (if needed)
