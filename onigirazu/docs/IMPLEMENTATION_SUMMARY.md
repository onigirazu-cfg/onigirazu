# Реализация поддержки вложенного синтаксиса модулей в Onigirazu

## 🎯 Цель

Реализовать поддержку вложенного синтаксиса модулей в Onigirazu и сделать его правилом по умолчанию для лучшей организации кода.

## ✅ Выполненные задачи

### 1. Техническая реализация

- **Модифицирован парсер YAML** в `pkg/types/types.go`
- **Добавлена поддержка двух синтаксисов**:
  - Плоский синтаксис (существующий)
  - Вложенный синтаксис (новый)
- **Обработка типов данных**: поддержка `map[interface{}]interface{}` и `map[string]interface{}`
- **Автоматическое определение синтаксиса** во время парсинга

### 2. Конфигурационная система

- **Добавлены настройки** в `internal/config/config.go`:
  - `preferred_module_syntax`: выбор предпочтительного синтаксиса

- **Поддержка переменных окружения**:
  - `ONIGIRAZU_PREFERRED_MODULE_SYNTAX="nested"`
  - `ONIGIRAZU_ENFORCE_MODULE_SYNTAX="true"`
- **Значения по умолчанию**: вложенный синтаксис установлен как предпочтительный

## 🔄 Поддерживаемые синтаксисы

### Плоский синтаксис (обратная совместимость)

```yaml
- name: "Install package"
  package:
  name: "tree"
  state: "present"
```

### Вложенный синтаксис (новый стандарт)

```yaml
- name: "Install package"
  module:
    type: "package"
    name: "tree"
    state: "present"
```

## 🚀 Преимущества вложенного синтаксиса

1. **Логическая группировка**: все параметры модуля сгруппированы под `module:`
2. **Четкое разделение**: параметры модуля отделены от параметров задачи
3. **Лучшая читаемость**: особенно для сложных задач с множественными параметрами
4. **Масштабируемость**: легче добавлять новые параметры модуля

## 🔧 Техническая архитектура

### Ключевые изменения в коде

1. **`Task.UnmarshalYAML()`** - основная логика парсинга
2. **Обработка типов данных** - поддержка interface{} ключей
3. **Извлечение параметров модуля** - из вложенной структуры
4. **Конфигурационная система** - настройки синтаксиса

### Алгоритм определения синтаксиса

1. Проверка типа поля `module`
2. Если `string` → плоский синтаксис
3. Если `map` → вложенный синтаксис
4. Извлечение `type` из вложенной структуры
5. Копирование остальных параметров
