### 2️⃣ Виправлення модуля config

**Проблема:** Модуль `config` виконував всі файлові операції локально

**Рішення:** Повна рефакторизація для віддаленого виконання

**Зміни:**

1. Додано поле `executor` до структури `ConfigModule`
2. Створено 4 допоміжні методи для віддалених операцій:
   - `checkFileExists()` - перевірка існування файлу
   - `readRemoteFile()` - читання файлу з віддаленого хоста
   - `writeRemoteFile()` - запис файлу на віддалений хост
   - `removeRemoteFile()` - видалення файлу з віддаленого хоста
3. Замінено всі `os.*` виклики на віддалене виконання
4. Додано екранування shell-аргументів для безпеки
5. Інтегровано автоматичне створення директорій

**Файли змінено:**

- `internal/modules/config.go` (~150 рядків)
- `internal/modules/registry.go` (реєстрація модуля)
- `internal/security/validator.go` (додано до дозволених модулів)

**Тестування:**

- Створено 2 тестові playbook'и
- Підтверджено віддалене виконання на реальному хості
- Всі операції виконуються на `cs.rastiegaiev.com`

### 3️⃣ Виправлення помилки компіляції тестів

**Проблема:** Тести не компілювалися через невідповідність типів

**Помилка:**

```
cannot use play (variable of struct type types.Play) as *types.Play value in argument to engine.executePlay
```

**Рішення:** Виправлено виклики методу `executePlay` у тестах

**Зміни:**

- `internal/core/core_engine_test.go` (2 рядки)
  - Рядок 184: `engine.executePlay(play, ...)` → `engine.executePlay(&play, ...)`
  - Рядок 237: `engine.executePlay(play, ...)` → `engine.executePlay(&play, ...)`

**Результат:**
