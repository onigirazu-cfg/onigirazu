## ⚡ Quick Commands

### Run Template Tests

```bash
go test -v -race -cover ./internal/template/...
```

### Run All Tests

```bash
go test -race ./...
```

### View Coverage Report

```bash
go test -cover -coverprofile=coverage.out ./internal/template/...
go tool cover -html=coverage.out
```
