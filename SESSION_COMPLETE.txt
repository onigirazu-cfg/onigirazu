═══════════════════════════════════════════════════════════════════
  🎓 KEY INSIGHTS
═══════════════════════════════════════════════════════════════════

1. EXECUTOR PATTERN
   All file operations on target host must use executor, not os.*

   ❌ WRONG: os.WriteFile(path, content, mode)
   ✅ RIGHT: executor.WriteFile(path, content, mode)

2. SHELL ESCAPING
   Use single-quote pattern for security:
   escaped := "'" + strings.ReplaceAll(text, "'", "'\\''") + "'"

3. TYPE SAFETY
   Go strictly checks types. If function expects *Type,
   pass &value, not value.

   ❌ WRONG: executePlay(play, ...)
   ✅ RIGHT: executePlay(&play, ...)

4. REMOTE VS LOCAL
   • Operations on target host → executor
   • Local operations (templates) → os.*
   • Commands → always executor
